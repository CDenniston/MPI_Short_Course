## Learning outcomes

After successful completion of this course, the student should have the reviewed and solidified skills and knowledge to

- gain an understanding of basic numerical parallel programming algorithms in C or C++ and how to apply them,
- understand and code algorithms using the Message Passing Interface C-library,

As a practical outcome, the students should learn the need for different operating systems and command interfaces, and how to do practical operations using the command line interface, installation of software, compilation of source codes, installation of libraries and how to resolve problems when they arise.


## Hands-on approach

- This course uses a hands-on approach: You will write programs in C or C++ using the MPI (and other) libraries, analyze data and learn methods. 


## Computers

This is a hands-on course and requires programming. This means that you *must* have a computer and the ability to install software on it. Any reasonably modern (past 7 years or so) laptop/desktop with Windows 10 or 11, Linux or MacOS should be ok. The methods have been tested using both older (7-10 year old laptops) and newer computers.

- The examples and tasks have been tested on Linux and Windows. 
- Due to no access to Apple-based systems, none of the examples have been tested on them.


> Some tasks can be CPU (or even GPU) intensive. To avoid overheating, thermal shutdown or, in the worst case, damage to your computer, always ensure that the ventilation openings are not covered. This is of utmost importance and the responsibility is solely yours.


## Software

Primary software that will be used (we will work through the installation procedures during the course):

- For plotting, data analysis you will need something like Python and Jupyter Lab / Notebook, and know how to use it.
- You will need to run examples in a linux-like environment so this requires installation of WSL if you are using Windows
- For later testing (not immediately) you will need access to a cluster computing environment which for this course will be assumed to be a Digital Research Alliance of Canada cluster.  If you do not have an account on such a cluster, you should get one as soon as possible (your supervisor needs to have an account first).
